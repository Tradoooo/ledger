# app-envelopes — requirements

- LED-F-16 The household application SHALL show `leftToday` first: one number, nothing else at first glance.
- LED-F-13 WHEN the user corrects a proposed assignment, the system SHALL store a `learned` rule
  (pattern → account) with a usage counter.
- The application SHALL import a French bank statement without asking where anything is.
- The application SHALL write no file outside its own folder and SHALL need no account.
