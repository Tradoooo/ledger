# FIXTURE: FICTIONAL DATA

Every file in this directory is **synthetic**. Names, labels, amounts and dates are
generated by `scripts/gen-fixtures.mjs` from the fixed seed `20261103`, and no real
person, account or transaction is represented. Regenerating the fixtures with the
same seed reproduces them byte for byte.

No IBAN, no card number and no real name may appear here: `.github/checks/fixture-privacy.mjs`
fails the build otherwise.
